# Дані для статей сторінок тем-фільтрів

## `articles-filters.sql` — шаблони головних тем (режим A)

15 `UPDATE filters SET description_uk/ru …` — по одному на кожну головну тему
(`type='theme'`, `parent_id IS NULL`): brendy, anime, mashiny, detskie, igry,
serialy-i-kino, patrioticheskie, prazdniki, zhivotnye, priroda, strany, vip,
futbolisty, futbolnye-kluby, memi.

Тексти містять плейсхолдери `#model#` / `#model_uk#` / `#model_ru#` — фронт підставляє
назву категорії, тож один шаблон обслуговує всі сторінки своєї теми.

**Стан:** написано 2026-08-04, на проді ще **не виконано** (виконує розробник вручну).
Порядок дій і запити для перевірки — у шапці самого файла.

Якщо в адмінці з'явиться нова головна тема — дописуй її `UPDATE` у кінець файла
окремим блоком з коментарем-роздільником і датою.

## `articles-filters-models.sql` — персональні статті пар «тема × модель» (режим B)

Файл створюється при першій пачці. Один `INSERT … ON DUPLICATE KEY UPDATE` у
`filters_expands` на кожну пару, перед кожним — коментар `-- {тема} × {модель} — кут: …`.

Ці тексти мають вищий пріоритет за шаблон теми, тому пишемо їх лише для моделей
із реальним трафіком. Перед новою пачкою пройдись по парах, які вже у файлі —
дублювати їх не можна.
