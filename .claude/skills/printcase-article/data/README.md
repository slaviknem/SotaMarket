# Дані для статей /printcase/{model}

## `articles-printcase.sql` — усі написані статті

**Один файл на всі моделі.** Нові статті **дописуємо в кінець**, нічого не видаляємо
й не розносимо по окремих файлах. Перед новою пачкою пройдись по alias у цьому файлі —
за ними видно, для яких моделей стаття вже є (дублювати alias не можна).

Кожна пачка відбивається коментарем-роздільником з датою, кожен `INSERT` —
коментарем з обраним кутом подачі.

## `c.sql` — вивантаження моделей з БД

Вибірка моделей, під які пишемо (запит із Кроку 1 у `../SKILL.md`), відсортована за популярністю.
Колонки: `alias`, `title_full`, `title_rus_uk`, `title_rus_ru`, бренд, лічильник, `has_article`.

Нове вивантаження клади сюди ж під іменем `models-{мітка}.json` або оновлюй `c.sql`.
У назвах моделей трапляються коми — для CSV бери роздільник `;` або обов&#39;язкове лапкування.
