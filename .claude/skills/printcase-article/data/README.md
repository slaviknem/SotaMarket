# Експорт моделей для статей /printcase/{model}

Сюди кладемо вивантаження з БД адмінки — вибірку моделей, під які пишемо статті
(запит із Кроку 1 у `../SKILL.md`).

**Файл:** `models-{дата або мітка пачки}.json`, наприклад `models-hit-2026-08-03.json`.
**Формат:** JSON (експорт phpMyAdmin / HeidiSQL «as JSON»), кодування UTF-8.
CSV теж підійде, але в назвах моделей трапляються коми — тоді експортуй з роздільником `;`
або обов&#39;язковим лапкуванням.

**Колонки, які мають бути в експорті:**
`alias`, `model` (title_full), `model_uk`, `model_ru`, `brend`, `has_article`.

Зроблені пачки не видаляй — по них видно, для яких моделей статті вже написані.
